# 주말캠프

주말캠프 학생 진도와 책 재고를 관리하는 웹사이트입니다. 서버 없이 `index.html`만 열면 동작합니다 (GitHub Pages로도 바로 올릴 수 있어요).

## 하는 일

- **진도**: 책을 다 푼 학생 이름만 적고 Enter → 다음 책으로 넘어가고, 다음 책 재고가 1권 줄어듭니다.
  - 책 순서: P1 → P2 → 1 → 2 → … → 12 (모든 학생이 순서대로 전부 풀어야 함). 12를 끝내면 '수료'.
  - 여러 명은 띄어쓰기·쉼표로 한 번에 입력. 잘못 넣었으면 '되돌리기'.
- **책 재고**: 책마다 지금 있는 권수 입력, 책이 들어오면 '재고에 더하기'.
- **구매 계획**: 지금 각 책을 푸는 학생 수로 다음에 필요한 책을 계산하고, 재고를 빼서 살 권수를 알려줍니다. 여유분, 몇 단계 앞까지 준비할지 고를 수 있어요.
- **기록·백업**: 모든 변경 기록, 백업 파일(JSON)·명단 CSV 받기와 불러오기.

## 데이터
